MCP QUEUE · 내 PC 연결

내 에이전트를 연결하세요.

설정 파일을 편집할 필요 없이, 평소 사용하는 도구와 문서 서비스를 선택하세요.

1

관리자에게 받은 연결 파일

본인 이름의 .queue.json 파일 하나면 됩니다.

서버 주소가 바뀌었나요?

2

평소 사용하는 에이전트

탐색기에서 폴더 주소를 복사해 붙여넣으세요. 기존 모델·문서 설정을 찾는 데 사용합니다.

설치를 찾지 못했을 때

아직 업무나 모델 추론을 실행하지 않습니다.

3

업무에 사용할 문서 서비스

기존 에이전트에 등록된 서비스 중 하나를 선택하세요.

사용할 검색·읽기 기능

필요한 기능만 선택하세요. 추천은 도구 설명에 따른 안내이며, 쓰기 기능이 포함되어 있지 않은지 확인하세요.

개인 에이전트 설정에 Queue가 추가됩니다. 기존 모델·문서 설정은 유지하고 변경 전 원본을 자동 백업합니다.

이 프로젝트에서 문서 서비스를 찾지 못했습니다. 평소 문서 MCP를 사용하는 프로젝트인지 확인하세요.

연결 준비 완료
