# 간편 시작

## 서버 관리자

1. 서버에 Git, Docker Engine/Desktop, Compose v2를 설치합니다.
2. `.env.example`을 `.env`로 복사합니다. 서버 HTTPS 주소와 회사 OIDC issuer/client_id/client_secret을 환경변수에 입력합니다. [설정 표](server.md).
3. 회사 OIDC에 `<서버 주소>/auth/callback`을 등록합니다.
4. `docker compose up -d --build --wait`를 실행합니다. 서버에는 Node.js·OpenCode·Claude Code를 따로 설치하지 않습니다.
5. 사용자에게 **Queue 웹 주소와 사용자 프로그램 ZIP**을 전달합니다. 사용자별 계정·키는 각 사용자가 로그인 후 직접 발급합니다.

사용자 ZIP은 [성공한 GitHub Actions](https://github.com/cwj980119/mcp-queue/actions)의 **Artifacts → mcp-queue-user**에서 받습니다. 비공개 저장소 접근 권한이 없는 사용자는 관리자가 제공한 ZIP을 사용합니다. 서버의 `.env`, `.local`, DB를 함께 전달하지 않습니다.

사내 OIDC 정보를 아직 모르면 `docker compose -f compose.yaml -f compose.dev.yaml up -d --build --wait`로 로컬 시험을 할 수 있습니다. 개발용 이름·이메일 로그인으로 동작하며 `http://localhost:3000`에만 공개합니다. 공용 서비스에는 사용하지 않습니다.

## 사용자

PC에는 Node.js 22.16 이상과 평소 사용하는 OpenCode 또는 Claude Code가 필요합니다. 기존 모델 API·로그인과 사내 문서 MCP가 정상 동작해야 합니다. 사용자 PC에 Docker나 Git은 필수가 아닙니다.

1. 관리자가 알려준 **Queue 웹 주소**에 접속합니다. 회사 로그인을 거쳐 자신의 계정이 자동 생성됩니다. 기존 SSO 세션이 있으면 회사 로그인 입력을 생략할 수 있습니다.
2. **내 PC 연결**을 열고 PC 이름을 입력한 뒤 **내 PC 연결 파일 다운로드**를 누릅니다.
3. 프로그램 ZIP을 풀고 **사용자-시작.cmd**를 더블클릭합니다. 첫 실행은 패키지를 설치·빌드하므로 사내 npm 레지스트리 또는 인터넷 접속이 필요합니다.
4. 열린 PC 설정 화면에서 방금 다운로드한 `.queue.json` 파일을 선택하고 **내 계정 연결**을 누릅니다.
5. **OpenCode / Claude Code** 중 하나를 고르고 평소 사용하는 프로젝트 폴더의 절대 경로를 입력합니다.
6. **프로젝트 확인**을 누르고 기존 문서 서비스와 사용할 검색·읽기 기능을 선택합니다.
7. **연결하고 시작 → 내 요청함 열기**를 누릅니다.

JSON 편집이나 토큰 복사가 필요하지 않습니다. 문서 기능 목록 확인에는 모델 토큰을 사용하지 않습니다. 선택한 도구가 실제 읽기 기능인지 확인하세요. OpenCode 전용 로컬 서버의 포트·비밀번호는 프로그램이 관리합니다. 4096에 접속하거나 서버를 수동으로 켤 필요가 없습니다. Claude Code는 CLI를 사용합니다.

Windows 시작 파일 대신 macOS/Linux에서 실행하려면 `npm ci`, `npm run build`, `npm run client` 순서로 실행합니다. PC 설정 화면은 기본 `http://127.0.0.1:3210`, 공통 업무 화면은 중앙 서버 주소입니다. 설치를 찾지 못하면 고급 설정에서 실행 파일 경로를 지정할 수 있습니다.

## 업무 처리

A가 웹이나 queue MCP로 B에게 질문을 보냅니다. B가 받은 요청함에서 **내 에이전트 실행 승인**을 누르면 B PC가 작업을 인수합니다. 에이전트는 B의 문서 MCP 권한으로 읽고 답변 초안을 만듭니다. B가 검토·수정 후 **검토한 답변 최종 전송**을 눌러야 A에게 답변이 공개됩니다.

다음부터는 사용자 시작 파일 실행 → **관리자 시작**으로 연결합니다. PC 프로그램과 PC가 켜져 있어야 실행합니다. 웹에서 조회·질문만 할 때는 PC 프로그램이 필요하지 않습니다. 사람의 승인·최종 전송은 회사 로그인된 웹에서만 수행합니다. PC 연결 파일로 웹에 로그인할 수는 없습니다.

## 연결 관리

웹의 **내 PC 연결**에서 등록한 PC와 마지막 연결·키 만료일을 확인하고 폐기합니다. 키는 기본 90일 유효합니다. 분실·만료 시 새 파일을 발급합니다. 원문 키는 서버에서 다시 다운로드할 수 없습니다. 폐기는 서버 접근을 막지만 이미 실행 중인 로컬 프로세스를 종료하지는 않습니다.

같은 계정에 여러 PC를 연결할 수 있습니다. 현재는 사용자당 동시 실행 1개이며 먼저 인수한 PC가 수행합니다. 처음에는 사용자당 PC 관리자 하나로 시험하세요. 어느 PC를 사용할지 지정하는 기능은 아직 없습니다.

연결 파일은 본인 PC에만 보관합니다. PC 정보 클레임이 있더라도 파일 복사를 막는 장치 인증은 아닙니다. 각 사용자 설정과 로컬 outbox는 기본 `~/.mcp-queue`에 저장됩니다. 기존 전역 에이전트 설정에 queue MCP·읽기 프로필을 병합하고 변경 전 백업을 만듭니다. 평소 실행하던 에이전트 프로세스를 종료하지 않습니다. 이 프로그램이 실행한 전용 OpenCode 프로세스는 중지 시 함께 종료합니다.
