Windows 10/11 x64 사용자용 설치 프로그램입니다.

1. **MCP-Queue-Setup.exe**를 다운로드하고 실행합니다.
2. **설치**를 누르면 필요한 실행 환경이 함께 설치되고 PC 연결 화면이 열립니다.
3. Queue 웹에 사내 로그인하여 **내 PC 연결 파일**을 다운로드하고 앱에서 불러옵니다.
4. 기존 OpenCode 또는 Claude Code와 프로젝트·문서 서비스를 선택합니다.

Node.js·npm·Git·Docker를 별도로 설치할 필요가 없습니다. OpenCode/Claude Code와 사내 모델·문서 MCP 설정은 미리 준비되어 있어야 합니다.

앱은 알림 영역에서 실행됩니다. 아이콘을 더블클릭하면 연결 화면이 열리고, 우클릭 → **종료**로 중지합니다. Windows 앱 목록에서 제거할 수 있으며 개인 연결 설정은 보존됩니다. 업데이트할 때는 실행 중인 앱을 종료한 뒤 새 설치 파일을 실행합니다.

설치 파일은 아직 코드 서명되지 않았습니다. Windows나 회사 보안 정책에 따라 확인 또는 차단될 수 있으며 회사 배포 정책을 따르세요. 인증서 검증이나 OS 보안 기능을 자동으로 끄지 않습니다.

`SHA256SUMS.txt`는 배포 파일의 체크섬입니다. 회사 내부 배포 시에도 원본과 비교할 수 있습니다.
