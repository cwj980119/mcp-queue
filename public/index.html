MCP Queue

요청을 받고, 승인하고, 답변을 검토하세요.

내 PC에 앱 설치

설치 파일 하나로 준비됩니다. 다운로드한 파일을 실행하고 설치를 누르면 PC 연결 화면이 열립니다.

Windows 앱 다운로드

Windows 10/11 · 64비트 · Node.js 별도 설치 불필요. 평소 사용하는 OpenCode 또는 Claude Code는 미리 준비하세요.

내 요청함 열기

로그인 설정을 확인하고 있습니다.

사내 계정으로 로그인

로컬 개발용 로그인입니다. 사내 인증을 사용하지 않습니다.

기존 토큰으로 로그인
내 PC 연결

Windows 앱을 설치한 뒤 연결 파일을 다운로드하고 앱에서 불러오세요. OpenCode 또는 Claude Code와 사용할 프로젝트를 선택하면 연결됩니다.

연결 파일은 발급할 때 한 번만 다운로드됩니다. 본인 PC에 보관하세요. 분실하거나 PC를 교체하면 아래에서 연결을 폐기하고 다시 발급하세요.

새 요청 보내기

문서 원문과 인증정보 대신 참조만 전달하세요. 받는 사람이 승인하면 해당 PC의 에이전트가 문서 MCP로 확인합니다.

받은 요청

요청을 선택하세요.

실행 승인 → 내 PC에서 처리 → 답변 검토 → 최종 전송
