MCP Queue 사용자 프로그램

1. PC에 Node.js 22.16 이상과 본인이 쓰는 OpenCode 또는 Claude Code를 설치합니다.
2. 관리자가 알려준 Queue 웹에 사내 계정으로 로그인합니다.
3. '내 PC 연결'에서 PC 이름을 입력하고 내 PC 연결 파일(.queue.json)을 다운로드합니다.
4. 사용자-시작.cmd를 더블클릭하고 다운로드한 연결 파일을 선택합니다.
5. 사용할 에이전트와 프로젝트 폴더, 문서 서비스를 선택하고 '연결하고 시작'을 누릅니다.
6. '내 요청함 열기'에서 요청을 보내고, 받은 업무를 승인하고, 답변을 검토해 전송합니다.

다음부터는 같은 시작 파일을 실행하고 '관리자 시작'을 누르면 됩니다.
프로그램 창과 PC가 켜져 있어야 승인된 업무를 처리합니다.
연결 파일은 에이전트 실행용입니다. 사람의 승인은 사내 로그인된 웹에서 합니다.
파일을 분실하거나 만료되면 웹의 '내 PC 연결'에서 폐기하고 새로 발급하세요.
개인 연결 파일을 다른 사람에게 공유하지 마세요.

Mac/Linux에서는 npm ci, npm run build, npm run client 순서로 실행합니다.
