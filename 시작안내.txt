MCP Queue 사용자 프로그램

1. PC에 Node.js 22.16 이상과 본인이 쓰는 OpenCode 또는 Claude Code를 설치합니다.
2. 사용자-시작.cmd를 더블클릭합니다.
3. 열린 화면에서 관리자에게 받은 본인 연결 파일(.queue.json)을 선택합니다.
4. 사용할 에이전트와 프로젝트 폴더, 문서 서비스를 선택하고 '연결하고 시작'을 누릅니다.
5. '내 요청함 열기'에서 요청을 보내고, 받은 업무를 승인하고, 답변을 검토해 전송합니다.

다음부터는 같은 시작 파일을 실행하고 '관리자 시작'을 누르면 됩니다.
프로그램 창과 PC가 켜져 있어야 승인된 업무를 처리합니다.
개인 연결 파일을 다른 사람에게 공유하지 마세요.

Mac/Linux에서는 npm ci, npm run build, npm run client 순서로 실행합니다.
