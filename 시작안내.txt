MCP Queue 사용자 설치

Windows 10/11 x64:
1. https://github.com/cwj980119/mcp-queue/releases/latest/download/MCP-Queue-Setup.exe 에서 설치 파일을 받습니다.
   Queue 웹의 'Windows 앱 다운로드' 버튼으로도 받을 수 있습니다.
2. 다운로드한 파일을 실행하고 '설치'를 누릅니다. Node.js·npm·Git·Docker는 따로 설치하지 않습니다.
3. Queue 웹에 사내 로그인하고 '내 PC 연결'에서 본인의 연결 파일(.queue.json)을 발급합니다.
4. 열린 앱에서 연결 파일을 불러오고 OpenCode/Claude Code, 프로젝트 폴더, 문서 기능을 선택합니다.
5. '연결하고 시작'을 누릅니다. 기존 에이전트와 모델·문서 MCP 설정은 미리 준비되어 있어야 합니다.

다음부터는 바탕화면의 MCP Queue 아이콘으로 실행합니다.
앱은 알림 영역에서 실행됩니다. 아이콘 더블클릭으로 화면을 열고, 우클릭 → 종료로 중지합니다.
실행 중인 앱을 종료한 뒤 새 설치 파일을 실행하면 업데이트할 수 있습니다.
개인 연결 설정은 앱 제거·업데이트 시 보존됩니다. 연결 파일은 다른 사람과 공유하지 마세요.

macOS/Linux 및 기존 소스 ZIP:
Node.js 22.16 이상에서 npm ci, npm run build, npm run client 순서로 실행합니다.
Windows의 사용자-시작.cmd는 이 소스 실행 방식입니다.
